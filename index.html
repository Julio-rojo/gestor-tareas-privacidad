Política de Privacidad

Gestor de Tareas

1. Datos recopilados

Gestor de Tareas permite introducir títulos, descripciones y estados de actividades. Estos datos se envían al servidor de la aplicación para su almacenamiento.

La versión académica utiliza una cuenta de prueba configurada en la base de datos. La interfaz actual no solicita al usuario crear una cuenta personal.

2. Finalidad

La información se utiliza para registrar, consultar, actualizar y eliminar tareas, así como para demostrar el funcionamiento de una aplicación web y Android.

3. Protección de información

El prototipo utiliza validaciones de datos, consultas SQL parametrizadas y una base de datos configurada en un entorno local. Las conexiones HTTP utilizadas durante las pruebas no ofrecen cifrado de transporte.

4. Almacenamiento y conservación

Las tareas se almacenan en una base de datos MySQL dentro de un entorno académico de pruebas. Los datos permanecen almacenados hasta que se eliminan mediante la aplicación o por el responsable del entorno.

5. Derechos sobre los datos

La aplicación permite eliminar tareas desde su interfaz. Para otras consultas relacionadas con los datos del prototipo, se puede contactar al responsable mediante el correo indicado a continuación.

Correo de contacto: juliorojo85@gmail.com

6. Alcance y limitaciones

Gestor de Tareas es un prototipo desarrollado con fines educativos. Actualmente utiliza un servidor local para las pruebas de funcionamiento y no está preparado para procesar información personal sensible.

No se debe introducir información confidencial en esta versión de pruebas.
